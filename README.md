# Homebrew Tap for Zyquo

Native macOS AI terminal agent runtime.

## Install

```bash
brew tap simonpierreboucher02/zyquo
brew install zyquo
```

## Usage

```bash
zyquo --help
zyquo doctor
zyquo ask "explain this repo"
zyquo run "fix failing tests"
zyquo interactive
```

## Update

```bash
brew upgrade zyquo
```

## Uninstall

```bash
brew uninstall zyquo
brew untap simonpierreboucher02/zyquo
```
